# Rifts source index (external PDFs)

Bibliography for designers and agents. Paths are relative to **`RIFTS_SOURCE_ROOT`** (default `D:\source\Rifts`). **Do not copy rule text into SpecialPG.**

Set locally in `.env` (see [.env/.env.example](../../.env/.env.example)):

```ini
# RIFTS_SOURCE_ROOT=D:\source\Rifts
```

| Column | Meaning |
|--------|---------|
| **PDF** | Path under `RIFTS_SOURCE_ROOT` |
| **Use when** | What to look up (themes, not stats) |
| **Phase** | See [scope-and-phases.md](scope-and-phases.md) |
| **Notes** | Reminders only — no copyrighted content |
